**Evidence window:** November 1, 2025 through September 22, 2026  
**Purpose:** Measure whether the saved Fortune 500 application record shows an interview-conversion advantage for (1) continued PhD research or (2) continued AWS/cloud development showcased through QCC capstone work.

## Audit rules

1. The employer screen uses the current 2026 Fortune 500 and includes clearly controlled subsidiaries of Fortune 500 parents.
2. The focused application record begins November 1, 2025 and ends September 22, 2026.
3. Acknowledgment, referral/introduction, recruiter reply, interview invitation, and interview completed are recorded as separate stages.
4. An application counts as interview-stage only when a recruiter proposed or confirmed a specific date/time for a call or interview.
5. An automated application acknowledgment is not interview-stage.
6. If a rejection explicitly cites a missing required qualification, that application is excluded from interview-stage totals in full.
7. Strategy 1 receives credit only if a qualifying interview-stage thread explicitly references the PhD research.
8. Strategy 2 receives credit only if a qualifying interview-stage thread explicitly references an AWS capstone project or GitHub link.
9. A single application may receive credit for both strategies, one strategy, or neither.
10. Employer-fit means Citigroup or a similar large financial-services / technology-risk organization.
